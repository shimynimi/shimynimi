# Statistical Analysis Plan

**Status:** proposed plan; to be finalized after a data-feasibility audit and before looking at primary ROI effect estimates.

## 1. Primary estimand

The primary estimand is the group-level mean within-participant first-level GLM coefficient for the dataset-defined emotional-intensity parametric modulator in each pre-specified affect-relevant ROI.

The dataset-defined emotional-intensity rating is generated by GPT-5 Nano from transcript content and ranges from −4 (very negative) to +4 (very positive). It will be treated as a signed, valence-like content annotation. It is not an arousal measure, a direct participant self-report, or a physiological measure of felt emotion.

## 2. First-level model

For each participant and each voxel/ROI time series:

`BOLD ~ sentence/speech events + affect-modulated sentence events + nuisance terms + drift`

The sentence/speech baseline regressor is unmodulated. A second event regressor uses the same sentence timings weighted by the participant-centered emotional-intensity rating. Both are convolved with the prespecified HRF. This models an affect-related modulation over and above the average speech-event response.

The exact handling of variable duration, modulation, and orthogonalization will be implemented and documented in a reproducible design-matrix function. The planned model must be inspected for rank deficiency, variance inflation, within-participant predictor variation, and correlations among columns before confirmatory inference. Because sentence events may be dense and closely spaced during continuous speech, an affect-modulator beta will only be interpreted if the design is estimable and diagnostics are acceptable; otherwise the proposed primary model must be revised before outcome testing.

## 3. Nuisance and behavioral covariates

Primary nuisance candidates:

- six rigid-body motion parameters;
- motion derivatives if supported and stable;
- CSF and white-matter signals if available and justified;
- low-frequency drift terms;
- high-motion spike regressors/censoring;
- a sentence/speech regressor to model overt speech.

Speech duration is already represented in variable-duration sentence events. Word count and speech rate may be added in sensitivity models rather than automatically adding all highly correlated speech features to the primary model. Thought-boundary/topic-transition terms are a sensitivity or adjusted model if available and reliably aligned.

The final nuisance set will be fixed using data quality and design diagnostics, without reference to the direction or significance of the primary ROI effects.

## 4. ROI family and multiple comparisons

Primary candidate ROIs: medial prefrontal cortex, insula, and amygdala. Exact masks/atlas labels will be recorded before the primary outcome analysis. The primary family will contain three ROI tests (or a smaller fixed set if feasibility requires it). Apply Benjamini–Hochberg FDR correction across this family at q = 0.05.

Any whole-brain or parcel-wise analysis is secondary and must apply an appropriate correction across all tested voxels/parcels. Uncorrected whole-brain p-values will not be presented as confirmatory evidence.

## 5. Group-level inference

The group-level unit is the participant. The primary analysis will use the subject-level affect beta in each ROI, with a random-effects group model or equivalent one-sample inference. Use two-sided tests because the direction of the effect is not sufficiently established for this dataset/annotation.

Report:

- number eligible and number analyzed;
- exclusion reasons and participant flow;
- mean beta, standard error, and 95% confidence interval;
- standardized effect size if appropriate;
- raw and FDR-adjusted p-values;
- design and model diagnostics.

Because the dataset has a fixed sample and no prospective recruitment, no conventional prospective power calculation is available. After the QC sample is known, report a detectable-effect or precision analysis rather than claiming the study is powered for any specific effect unless supported by calculation.

## 6. Missingness and exclusions

Report missing ratings, missing timestamps, missing confounds, and unusable images separately. Do not impute missing sentence ratings in the primary analysis. Exclude participants only according to prespecified data completeness and quality rules. Any deviations must be documented.

## 7. Robustness analyses

1. **Motion:** compare the primary mean-FD threshold with a stricter or continuous-motion sensitivity specification; document how N changes.
2. **HRF:** repeat with a temporal derivative or alternative reasonable HRF if the design remains stable.
3. **Derivative choice:** compare fMRIPrep-preprocessed BOLD with the dataset-provided denoised derivative, avoiding duplicate regression of the same nuisance variables.
4. **Speech covariates:** compare baseline speech-event model with a sensitivity model including word count/speech rate and/or thought-boundary terms.
5. **Human ratings:** repeat with mean human rating or rater-level approach on the 18 available transcripts only; describe its sampling restriction and small N.
6. **Exploratory affect dimensions:** sadness and anxiety, clearly separate from the primary hypothesis.

## 8. Statistical safeguards

- Do not treat sentences as independent subjects.
- Do not select ROIs based on the same statistical maps used for testing them.
- Do not tune the model using the test/outcome data or report the most favorable model only.
- Do not use clinical labels or questionnaire subgroups as diagnosis.
- Report null and unstable effects.
- Preserve a dated analysis plan and log all deviations.
